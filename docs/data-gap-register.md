# Data-Gap Register — Education Expenditure & Accountability

*What could NOT be sourced online, drafted as specific, filable RTI questions grouped per
PIO/department (per `docs/rti/README.md` conventions: Section 6 application, information in
electronic form under Section 7(9), one application per PIO). Maintainer files; each group
below carries its **mine-before-file evidence note** — what was checked online and found
missing, which is the justification trail.*

*Companion to `docs/education-spend-discovery.md` (where every negative finding below is
sourced with URL + access date). Default period: **FY 2021-22 to 2025-26** (latest available);
adjust per item where the trigger event is dated.*

**Legend:** each numbered item is a filable question. `[doc]` = also request a copy of the
underlying document, not just figures.
